# Раздел 01. Ментальная модель React

Этот раздел отвечает на главный вопрос курса: почему React называется React, хотя он не отслеживает произвольные мутации как Vue.

React реагирует не на каждую запись в JavaScript-объект, а на явно переданные ему сигналы: новый state, props или Context value. После сигнала React снова вызывает компоненты и получает новый snapshot UI. Значения, локальные переменные и handlers конкретного рендера не изменяются задним числом.

Во Vue ref и reactive создают отслеживаемые зависимости. В React обычные JavaScript-значения остаются обычными значениями, а состояние рассматривается как последовательность snapshots. Это не менее реактивная, а другая модель реактивности.
