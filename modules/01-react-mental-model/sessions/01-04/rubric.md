# Rubric 01-04

## Обязательно

- Handler выполняет три отдельных setter-вызова.
- Каждый setter получает updater function.
- Updater не читает count из внешнего render scope.
- Нет искусственной асинхронности.

## Причина ограничения

Цель упражнения — увидеть очередь updater-функций, а не найти самое короткое арифметическое выражение.
