# Rubric 01-04

## Обязательно

- Handler выполняет три отдельных setter-вызова.
- Каждый setter получает updater function.
- Каждый updater представляет один шаг очереди: возвращает переданное previous value
  плюс один, а не читает внешний render scope или другую mutable-переменную.
- Updater чистый: не мутирует вход, не выполняет побочные эффекты и не меняет
  внешнее состояние.
- Нет искусственной асинхронности.

## Причина ограничения

Цель упражнения — увидеть очередь updater-функций, а не найти самое короткое арифметическое выражение.
