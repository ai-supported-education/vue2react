# Rubric 01-01

## Обязательно

- Все ответы выбраны до проверки.
- Reason объясняет наблюдаемое значение через render snapshot.
- Setter описывается как запрос следующего рендера.
- Прямая мутация не считается сигналом React.

## Не требуется

- Знать внутреннее устройство Fiber.
- Объяснять scheduler или concurrent rendering.
- Писать React-компонент.
