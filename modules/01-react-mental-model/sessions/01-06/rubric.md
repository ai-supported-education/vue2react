# Rubric 01-06

## Обязательно

- Derived value не помещён в state и effect.
- Пользовательское действие обрабатывается в event handler.
- Effect используется только для внешней синхронизации.
- Shareable filter принадлежит URL.
- Server state принадлежит query cache.
- Ref не используется для значения, которое должно отображаться.
- Context объяснён как доставка theme value/callback от владельца App, а не как
  самостоятельный владелец state или универсальный store.
- Для каждого ответа указан Vue-аналог и граница аналогии.

## Итог раздела

Учащийся может объяснить фразу: React реактивен к явным изменениям своего состояния, но не превращает произвольные JavaScript-объекты в отслеживаемые reactive proxies.
