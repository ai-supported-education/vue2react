# Rubric 01-03

## Обязательно

- Нет присваивания в profile или prevProfile.
- Setter получает новый объект.
- Новое значение вычисляется из предыдущего state.
- Неизменяемые поля сохраняются.

## Антипаттерны

- Мутация с последующим поверхностным clone.
- Отдельный dummy state для принудительного рендера.
- Effect, наблюдающий profile.
