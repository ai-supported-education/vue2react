# Rubric 01-03

## Обязательно

- Текущий и переданный React предыдущий state snapshot не мутируют независимо от
  выбранных имён переменных.
- Setter получает updater function, которая возвращает новый объект.
- Новое значение вычисляется из аргумента previous state, который React передаёт
  в updater function, а не из объекта, замкнутого текущим render.
- Неизменяемые поля сохраняются.

## Антипаттерны

- Мутация с последующим поверхностным clone.
- Отдельный dummy state для принудительного рендера.
- Effect, наблюдающий profile.
